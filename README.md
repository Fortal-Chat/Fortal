# Chat — аналог Discord

Сообщества, каналы, личные сообщения, позже голос. Микросервисная архитектура, старт с минимального набора.

## Структура

| Папка | Что там будет | Ведёт |
|---|---|---|
| `docs/` | договор API (`docs/api.md`) и прочая документация | оба, через PR |
| `server/` | основной сервер: Kotlin + Ktor (регистрация, вход, сообщества, каналы, сообщения) | напарник |
| `gateway/` | gateway: C++, WebSocket, рассылка событий в реальном времени | я |
| `desktop/` | desktop-клиент: C++, Qt 6 | я |
| `android/` | Android-клиент: Kotlin, Jetpack Compose | напарник |
| `deploy/` | выкладка на VPS (этап 5) | — |
| `.github/workflows/` | CI (GitHub Actions) | оба |

## Как работаем

- `main` защищён: изменения только через Pull Request, нужно одобрение второго, ревью в течение суток, PR до ~300 строк.
- Договор API меняется только общим PR.
- «Готово» = код в `main`, есть тесты, договор обновлён, всё запускается через `docker compose up`.
- Секреты только в `.env` (не в Git). Порты на роутере не пробрасываем.

## Этапы

0. Подготовка: репозиторий, доска, Docker с PostgreSQL, договор v0, «Hello World» каждой части, Tailscale, CI
1. Регистрация и вход
2. Сообщества и каналы
3. Сообщения (без реального времени)
4. Реальное время: gateway + Redis
5. Выкладка в интернет: VPS, nginx, HTTPS, нагрузочные тесты
6. Новые возможности по одной
7. Масштабирование (только по замерам)
8. Голос (LiveKit)
